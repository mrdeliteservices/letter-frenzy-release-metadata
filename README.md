# Letter Frenzy release metadata

This public repository hosts **Message Center release-date metadata** for Letter Frenzy.

**Owner:** MRD Elite Services / Frenzy Apps

## Contents

- `message-publish-dates.v1.json` — publication dates for Message Center messages (calendar dates only)

## Security

- No customer data
- No secrets or credentials
- No application source code (the Letter Frenzy app remains in a private repository)

## Updates

Updates are published through the authoritative Letter Frenzy release workflow after schema validation. Do not edit dates casually; TestFlight dates are App Store Connect acceptance calendar dates, and production dates are public App Store availability dates.

## Schema

JSON is validated before deployment (`version` schema, `YYYY-MM-DD` dates, approved sources).
